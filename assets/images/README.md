Images directory for portfolio assets.

Download non-licensed stock photos and place them here:

1. hero-workspace.jpg - Workspace with electronics, boards, and tools
2. drone-v2.jpg - Autonomous aircraft platform or PCB top-down view
3. code-sdr.jpg - RF board or FPGA development platform
4. physics-sim.jpg - Simulation visualization (CFD or quantum simulation)

Recommended sources:
- Unsplash (unsplash.com) - Free, professional photos
- Pexels (pexels.com) - High-quality royalty-free images
- Pixabay (pixabay.com) - More tech-focused stock photos

Images should be:
- Minimum 1200x600px (landscape format recommended)
- Optimized for web (JPEG or PNG, <500KB each)
- High contrast and clean composition
