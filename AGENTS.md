# Project instructions

## Persistent user preferences

- When the user says "inters", they mean the Interests page (`interests.html`).
- Work autonomously: make reasonable design and implementation decisions without repeatedly asking for approval when the intent is clear.
- For multi-pass website work, do not end the turn with intermediary progress updates. Complete the requested passes, verification, and cleanup first, then report the final result and remaining limitations.
- The user values a polished, authored interface over generic AI-sounding copy, decorative dashboards, weak stock imagery, and unverified claims.
- Preserve Jekyll/GitHub Pages compatibility and distinguish local preview from deployed public site.
